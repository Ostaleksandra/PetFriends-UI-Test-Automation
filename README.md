# PetFriends UI Test Automation

Автоматизированные UI-тесты для проверки страницы **«Мои питомцы»** на сайте PetFriends.

##  Описание проекта

Проект содержит автоматические тесты для проверки корректного отображения информации о питомцах пользователя на сайте PetFriends.

Тестирование выполняется с использованием **Selenium WebDriver** и **pytest**.

Тестируемая страница:
https://petfriends.skillfactory.ru/login

После авторизации тесты проверяют страницу **«Мои питомцы»**.

##  Проверяемый функционал

Тесты проверяют следующие требования:

* на странице присутствуют **все питомцы пользователя**
* **хотя бы у половины питомцев есть фотография**
* у каждого питомца указаны:

  * имя
  * порода
  * возраст
* **имена питомцев не повторяются**

##  Используемые технологии

* Python 3
* pytest
* Selenium WebDriver

Пример запуска тестов:

```id="b67etx"

```

##  Авторизация

Авторизация выполняется автоматически через фикстуру `selenium_driver`,
которая:

1. открывает страницу входа
2. вводит email и пароль
3. выполняет вход в систему

После этого тесты переходят на страницу **«Мои питомцы»**.

##  Цель проекта

Практика:

* написания UI автотестов
* работы с Selenium WebDriver
* использования pytest и фикстур
* поиска элементов страницы через CSS-селекторы и XPath
